# Catalog import paths follow SUNAT's catalogs, not our convenience

Catalogs that more than one document uses are imported from `tribu/catalogs`. A Catalog that belongs to a single document is imported from `tribu/catalogs/<document>`, for example `Reason` from `tribu/catalogs/credit-note` and from `tribu/catalogs/debit-note`. Constant names translate SUNAT's official wording, in PascalCase and at most two levels deep (`Reason.Item.Return`). Tax Affectation (catalog 07) is `Affectation`, not `Tax`, because `Tax` is reserved for catalog 05 (tax types: IGV, ISC, ICBPER). An earlier draft used `Tax.Exempt`, which would have left catalog 05 without a name. The Issuer's IGV Regime (`igv`) and an Item's `affectation` answer different questions: how much IGV the business charges, and whether the Item pays it at all.
